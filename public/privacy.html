Privacy policy — banking-pwa

banking-pwa is a personal-use Progressive Web App that displays the owner's bank transactions with automatic categorisation.

Data collected

  • Bank transactions (date, label, amount) imported either from a CSV file or fetched via the Enable Banking API (PSD2 account information service).
  • User-defined settings (budgets, classification rules, period).

How it is stored

  • All personal data is stored locally on the user's device (browser localStorage).
  • Short-lived API tokens (access/session tokens issued by Enable Banking) are cached in a Cloudflare Worker KV namespace operated by the user, only for the time required to complete API calls.
  • No analytics, no tracking, no third-party scripts, no cookies beyond what is strictly required for the PWA to function.

Data sharing

No data is shared with any third party other than the APIs the user explicitly authorises (Enable Banking and the corresponding bank under the PSD2 framework).

Data retention

Data is retained until the user clears it from the app ("Effacer toutes les transactions" in Settings) or clears browser storage.

User rights

The user is the sole operator and data controller of this application. They can access, modify and delete all data at any time directly from the app interface.
